# Engage Management System

Local-first school staff absence and substitute allocation app.

## Run
1. Install Node.js 18 or newer.
2. In this folder run `npm i`.
3. Run `npm run dev` and open the URL shown by Vite.

## Demo
Includes 20 editable dummy teachers, Classes 6–10, and the supplied Monday–Thursday 7-period / Friday 5-period subject schedule. Demo schedule uses fictional teacher assignments; replace names and verify subject assignments before real use.

## Privacy
Data stays in this browser's localStorage. Export a JSON backup from Settings.
